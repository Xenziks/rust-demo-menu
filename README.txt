RUST — ДЕМО-МЕНЮ ДЛЯ WINDOWS

Как собрать установщик:
1. Распакуйте папку проекта.
2. Установите Node.js LTS, если он ещё не установлен: https://nodejs.org/
3. Дважды щёлкните СОБРАТЬ_EXE.cmd.
4. Дождитесь окончания сборки.
5. Установщик Rust Setup.exe появится в папке dist.

После установки запускайте приложение через ярлык Windows — BAT для запуска игры не нужен.

Важно: это демонстрационное меню Rust, а не полноценная игра Rust. Кнопки «Новая игра», «Кампания», «Выживание» и подключение к серверам показывают демонстрационные сообщения.
